```text
public/characters/ari/ari.glb
```

Requirements, clip names, and art direction are documented in:

- `docs/ASSET_CONTRACT.md`

The reference still image is **not** a substitute for this file. Until `ari.glb` exists, the app keeps the Rive → SVG Ari fallbacks.
